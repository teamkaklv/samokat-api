# Автоматизация теста API сервиса «Самокат»

## Описание проекта

Проект содержит автоматизированный тест API сервиса «Самокат».

В рамках теста проверяется следующий сценарий:

1. Создание нового заказа через POST-запрос.
2. Получение трек-номера созданного заказа из ответа сервера.
3. Получение заказа по трек-номеру через GET-запрос.
4. Проверка HTTP-статусов ответов.

## Структура проекта

- `configuration.py` — содержит базовый URL тестового стенда.
- `data.py` — содержит тело POST-запроса для создания заказа.
- `sender_stand_request.py` — содержит функции для отправки POST- и GET-запросов.
- `create_order_test.py` — содержит автоматизированный тест.
- `sql_queries.sql` — содержит SQL-запросы для выполнения заданий проекта.
- `2026-09-24_11-21-05.png` — скриншот успешного запуска автотеста.
- `.gitignore` — содержит файлы и папки, которые не должны добавляться в Git.
- `README.md` — описание проекта и инструкция по запуску теста.
